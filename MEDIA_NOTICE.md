# Media Notice and Provenance Registry

## Scope

The repository MIT license applies to source code only unless an asset entry
explicitly states otherwise. Source-code license does not grant media rights.
No approved human media assets are present in M0.3.

The deterministic non-person fixture may be committed for tests. A media or
object-storage provider remains unselected; this notice does not select one.

## Publication gate

Every future media asset needs one complete non-personal registry row before it
is publishable. Private release records stay outside Git. The release record
must document record, edit, public-demo, and redistribution rights. Deletion
from HEAD cannot guarantee revocation from Git history, forks, caches, or any
already published copy.

Allowed publication scope is `PUBLIC_REPOSITORY_AND_DEMO`. `Status` is either
`FIXTURE` or `CLEARED`. An absent or mismatched field is not publishable.

|---|---|---|---|---|---|---|---|---|---|

The registry currently has zero asset rows. No approved human media assets are
present.

## Boundary

The browser loads approved reference media and captions directly. The backend
and database never upload, store, proxy, or stream media bytes. This registry
contains no private release, personal data, cloud credential, or storage choice.
